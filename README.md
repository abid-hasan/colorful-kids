# Colorful Kids

চার বছরের শিশুর জন্য রং এবং বাংলা, ইংরেজি ও আরবি বর্ণ শুনে চেনার ওয়েব অ্যাপ। Chrome-এর ল্যাপটপ ও মোবাইল বিন্যাসের জন্য তৈরি।

## লোকালি চালানো

Node.js 22.12+ (অথবা সমর্থিত নতুন সংস্করণ) লাগবে।

```sh
npm install
npm run dev
```

তারপর http://127.0.0.1:5174/ খুলুন। পোর্টটি ব্যস্ত থাকলে `npm run dev -- --port 5175` চালান।

Production build:

```sh
npm run build
npm run preview
```

`npm run preview` যে লোকাল ঠিকানা দেখাবে, সেটি খুলুন। সরাসরি `index.html` ডাবল-ক্লিক করে নয়, এই সার্ভার ব্যবহার করে অ্যাপ চালাতে হবে।

## কী আছে

- চারটি বিষয়: ১০ রং, ৫০ বাংলা বর্ণ, ২৬ ইংরেজি অক্ষর এবং ২৯ আরবি হরফ।
- প্রতিটি বিষয়ে ট্যাপ করে শেখা এবং পাঁচ প্রশ্নের খেলা। বর্ণমালা ছোট দলে ভাগ করা; সব বর্ণই পাওয়া যায়।
- প্রথম ভুলেই সঠিকটি বড় করে দেখিয়ে নাম শোনানো হয়। “পরেরটি” চাপলে পরের প্রশ্ন আসে; পুনরায় প্রশ্ন ফিরিয়ে আনার লুপ নেই।
- সঠিক উত্তরেও নামটি আবার শোনানো হয়। নিজে চেনা প্রশ্নে তারা, সাহায্যে শেখা প্রশ্নে check—ফলাফলে আলাদা হিসাব।
- প্রতি প্রশ্নে ৪টি অপশন। বড় replay বোতাম এবং কিছুক্ষণ নিষ্ক্রিয় থাকলে একবার স্বয়ংক্রিয় replay। অডিও ব্যর্থ হলে উত্তর বন্ধ থাকে; retry করা যায়।
- শুধু বাংলা / English UI toggle; রঙের অডিও নির্বাচিত ভাষায়, বর্ণের অডিও সেই বিষয়ের ভাষায়।
- ভাষা ও কোন নাম শুনেছে তা স্থানীয় ব্রাউজারে মনে থাকে। শোনা মানে শেখা সম্পূর্ণ—এমন দাবি করা হয় না।
- নাম সবসময় Colorful Kids। কোনো settings, footer, অ্যাকাউন্ট বা runtime TTS নেই।

প্রথমবার খেলা শুরু বা রঙে চাপ দেওয়ার পর শব্দ বাজে। ট্যাব আড়ালে গেলে খেলা থামে; ফিরে এসে আবার চালানো যায়। সাউন্ড সবসময় চালু। ডিভাইসের reduced-motion accessibility preference সম্মান করা হয়; অ্যাপের ভেতরে এই সেটিং নেই।

## GitHub Pages

1. নিজের GitHub repository-তে সোর্স ফাইলগুলো রাখুন।
2. Settings → Pages → Build and deployment → Source: **GitHub Actions** নির্বাচন করুন।
3. `main`-এ push করলে `.github/workflows/deploy.yml` build করে `dist/` প্রকাশ করবে। অন্য default branch হলে workflow-এর branch নাম বদলান।

Vite-এর relative base (`./`) repository subpath-এ assets চালানোর জন্য কনফিগার করা। একটিমাত্র HTML entry হওয়ায় SPA rewrite লাগবে না। প্রকাশের আগে স্থানীয় পরিবর্তনগুলো নিজে পর্যালোচনা করে commit ও push করুন।

## অডিও ও ফন্ট

অডিও আগে থেকেই `public/audio/bn/` ও `public/audio/en/`-এ আছে। অ্যাপ চালাতে Python, Azure, API key বা TTS সেবা লাগে না। মডেলগুলো ওয়েবসাইটে লোড হয় না।

- অডিও উৎস ও ব্যবহারের শর্ত: `public/AUDIO-LICENSE.md`
- মডেল revision, পাঠ্য, hash ও যাচাই: `public/audio/provenance.json`
- `scripts/generate_audio.py` ও `scripts/voice-requirements.txt` পুরোনো MMS কণ্ঠের জন্য; বর্তমান Google voice pack পুনরায় তৈরি করে না।
- Baloo Da 2 ও Nunito ফন্ট self-hosted; SIL Open Font License কপি `public/fonts/`-এ আছে।

Google AI Studio-র Gero পুরুষ কণ্ঠে ২৬টি ক্লিপ বসানো হয়েছে: দুই ভাষায় দশটি রঙের নাম ও সঠিক/ভুল/সমাপ্তির প্রতিক্রিয়া। বর্তমান flow-তে ভুল উত্তরের পুরোনো “আবার চেষ্টা করো” / “Let’s try again” ক্লিপ ব্যবহার হয় না; তার বদলে সঠিক item-এর নাম শোনানো হয়। সব WAV-এর দৈর্ঘ্য ও শব্দের উপস্থিতি এবং MP3 decoding যাচাই হয়েছে। মূল WAV `audio-source/google-ai-studio/`-এ আছে।

আরও ১০৫টি Gero বর্ণমালার ক্লিপ `public/audio/alphabets/`-এ আছে; provenance একই ডিরেক্টরিতে। সংশোধিত উচ্চারণ ও বাংলাদেশি আরবি ক্রম রাখা হয়েছে। মূল ব্যাচ, কাটার তথ্য ও শোনার পেজ `audio-source/alphabets/`-এ সংরক্ষিত। উচ্চারণের শ্রবণ-যাচাই অভিভাবকের সঙ্গে করা উচিত।

## কাজের কাঠামো

- `src/main.ts`: খেলার অবস্থা, স্ক্রিন ও ভাষা
- `src/i18n.ts`: দুই ভাষার UI লেখা
- `src/colors.ts`: রঙের তালিকা ও shuffle
- `src/curriculum.ts` ও `src/alphabets.json`: বিষয়, বর্ণ, শেখার দল এবং অডিও mapping
- `src/audio.ts`: একবারে একটি ভয়েস এবং নরম প্রতিক্রিয়ার শব্দ
- `src/style.css`: responsive UI, animation, reduced motion

ম্যানুয়ালি যাচাই করুন: দুই ভাষায় শুরু, সঠিক/ভুল উত্তর, প্রথম ভুলে দেখিয়ে শেখানো, পাঁচ রাউন্ড শেষ, ভাষা পাল্টানো, বিরতি এবং ছোট স্ক্রিন। কোনো স্বয়ংক্রিয় test file যুক্ত করা হয়নি।

## পরবর্তী mobile release

বর্তমান release নাম ও বর্ণ চেনা শেখানোর ভিত্তি। Phonics, tracing, শব্দ, সংখ্যা ও আকৃতি আলাদা content/learning design হিসেবে পরের ধাপে যুক্ত করা যাবে। প্রথমে শিশুর সঙ্গে ব্যবহার করে flow ও উচ্চারণ নিশ্চিত করুন।

Curriculum, playback এবং UI পৃথক রাখা হয়েছে। পরবর্তী mobile release-এ এই data ও audio পুনর্ব্যবহার করা যাবে। তার আগে offline asset updates, durable progress, native audio lifecycle এবং parent controls-এর প্রয়োজন নির্ধারণ করুন। এই release-এ service worker বা app-store package যুক্ত হয়নি।

বর্তমান খেলায় সঠিক, ভুল ও সমাপ্তির প্রতিক্রিয়া শুধু সাউন্ড ইফেক্টে দেওয়া হয়। পুরোনো feedback voice ক্লিপগুলো সংরক্ষিত আছে, কিন্তু অ্যাপ বাজায় না। রং ও বর্ণের নামের ভয়েস চালু থাকে।


### বর্তমান শেখা ও খেলার নিয়ম

আগের ছোট দলের নিয়মের পরিবর্তে শেখায় পুরো বর্ণমালা এক তালিকায় থাকে। খেলায় পুরো বিষয় থেকে পাঁচটি আলাদা প্রশ্ন আসে; একই পেজ খোলা থাকা অবস্থায় পরের পর্বে আগে না-আসা প্রশ্ন অগ্রাধিকার পায়। প্রথম ভুলে চারটি অপশন একই জায়গায় থাকে: সঠিকটি সামান্য বড়, বর্ডার ও চেকসহ দেখা যায়, বাকিগুলো ম্লান হয়। সঠিকটিতে ট্যাপ করলে নাম আবার শোনা যায়। নামের পরে Next চালু হয়। ফলাফলে নিরপেক্ষ সমাপ্তির লেখা, স্বাধীন ও সহায়তাপ্রাপ্ত উত্তর আলাদা; feedback শুধুই সাউন্ড ইফেক্ট।
